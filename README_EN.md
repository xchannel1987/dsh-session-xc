A DSH plugin that enhances workspace session management.

## Features

- **Session Count Display**: Show active and unread completed sessions per workspace
- **Archived Sessions**: View, restore, and delete archived sessions
- **Batch Delete**: Delete multiple archived sessions at once
- **Cross-Workspace Move**: Move sessions between workspaces

## Installation

```bash
dsh plugin --profile web add dsh-session-xc
```

## Configuration

Configure via "Session Enhancement" settings card in DSH settings.

## Requirements

- Node.js >= 18
- DSH >= 0.1.0-rc.2
